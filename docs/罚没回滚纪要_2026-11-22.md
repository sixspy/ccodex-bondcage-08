# 罚没回滚纪要（2026-11-22 当日锁死）

> 本纪要为保证金笼「罚没回滚」能力的唯一治理口径。文件摘要在首个业务日由
> `rollback_minutes_seal` 封存，封存后任何字节变动均判 **回滚偏航**，回滚请求拒写。
> 适用库：`data/app.db`（库路径不变）；页面会话沿用登录态与既有角色（admin/clerk 可写，viewer 只读）。

## 一、事故背景

操作员点错合约发起罚没：罚没册已生成凭证，笼内可用额被抽空（available=0），
当事人账户余额与冻结额双双被扣，页面只展示「已罚没」字样却没有任何回滚口。
此类「凭证在册、资金无法归还」的状态称为 **假绿事故**：流程显示办结，账实却无可救济路径。

## 二、正确性口径（二选一，不得混用）

罚没回滚必须让 **罚没作废** 与 **笼面归还** 一次落地，只允许以下两种口径中的一种：

- **甲路径：整笔原子提交（本仓选定，唯一启用）**
  同一数据库事务内完成：目标罚没标记作废 → 笼可用额归还 → 账户冻结额与余额归还
  → 写罚没回滚凭证 → 写审计。任一步失败，作废与归还整体回滚，罚没册、笼面、账户零改。
- **乙路径：回滚意图影子单晋升（本仓禁用）**
  先登记影子单、确认后再原子切换的做法禁止实现、禁止调用。请求显式携带乙路径模式
  （`影子单晋升` 等）一律判回滚偏航并拒写。

**两边不得混用**：系统中不存在影子单表、晋升接口与半提交状态；任何绕开甲路径单事务的
写法（包括只把罚没页字样改成「撤销」而不还资金）均为偏航。

## 三、甲路径事务纪律

1. 回滚接口 `POST /api/forfeits/rollback` 在同一连接同一事务内依次落库：
   1. `forfeits` 目标行 `status` 置「已作废」，记 `voided_at`、`voided_by`、`rollback_ref`；
   2. `cages.available` 加回罚没金额；同笼代无其他在册罚没时笼状态回退「核验违约」，否则保持「部分罚没」；
   3. `bond_accounts.frozen` 与 `bond_accounts.balance` 同额加回；
   4. `forfeit_rollbacks` 写回滚凭证（含本纪要摘要、业务日、操作员）；
   5. `audit_trail` 写 `cage_forfeit_rollback` 审计。
2. 事务中途任何异常 → 回滚整笔，五张表均无部分写入；锁在 finally 释放，争用痕保留。
3. 同一罚没只允许成功回滚一次：重复请求 409 拒写，依赖 `forfeit_rollbacks.forfeit_id UNIQUE` 与行状态双保险。
4. 笼代校验：罚没凭证的 `cage_generation` 必须与当前笼代一致，不一致判偏航拒写。

## 四、并发纪律

- 两人同时回滚同一罚没，必须先抢 `cage:{cage_id}` 笼锁（复用 `cage_locks`/`contention_log`）。
- 先到者持锁完成整笔事务；后到者抢锁失败仅在 `contention_log` 留争用痕，返回 409，
  不写任何业务数据（罚没册、笼面、账户、回滚凭证、审计均零改）。

## 五、五页账实同源

罚没页、入笼页、账户页、对账页、审计页共用同一 SQLite 库与同一套状态口径：

- 罚没页：在册罚没显示「已罚没」，作废罚没显示「已作废」并附回滚凭证号；回滚按钮触发真实甲路径事务。
- 入笼页：笼 available 随回滚立即恢复，笼详情内嵌罚没条目的作废状态与回滚凭证。
- 账户页：balance/frozen 随回滚同额恢复，可用 = 余额 − 冻结恒成立。
- 对账页：`available + released + forfeited(在册) == amount` 恒平衡；单列「回滚归还」，
  并给 `rollback_integrity` 标识：每条作废罚没必有同额回滚凭证，无凭证作废即假绿，对账判失败。
- 审计页：回滚成功落 `cage_forfeit_rollback`，偏航拒写落 `rollback_yaw`，争用落 contention。

## 六、偏航处置（回滚偏航，拒写留痕）

以下情形一律拒绝业务写入，并在审计落 `rollback_yaw`（偏航审计独立提交，不受业务回滚影响）：

1. 纪要文件缺失、关键字缺失或与当日封存摘要不一致；
2. 请求显式要求乙路径/影子单晋升，或甲路径之外的任何模式；
3. 笼代不一致、罚没已作废仍请求重复回滚等数据完整性冲突。

## 七、当日锁死与验收

- 业务日 2026-11-22 首次回滚前，系统对本纪要做 SHA-256 摘要并写入 `rollback_minutes_seal`；
  此后每次回滚校验摘要，不符即偏航。封存行按业务日主键唯一，不可覆盖。
- 验收：假绿事故夹具可在本机文件库复现；罚没回滚无效失败测、双人同回滚争用失败测
  先红后绿；回滚后罚没作废且笼可用、账户冻结/余额归还，五页同源对账平衡。
